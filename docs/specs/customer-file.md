# Customer File

The customer directory opens a read-only file using the existing customer URL. The file presents the profile and paginated Timeline, Leads, Quotations, Bookings, Finance, Inbox and Emails sections. Related rows use stored identifiers, including the customer snapshot on the quotation revision used for email and chat. Finance remains administrator-only. Staff see quotations, bookings, conversations and delivery records according to the owning module's policy.

The timeline uses persisted CRM activity and dated records. Booking rows include cancelled bookings. Quotations distinguish created links, logged email acceptance and commercial status. Payments preserve original currency, amount, direction and verification status. The file can start a linked manual invoice. Administrators can link an existing social conversation from Inbox. Existing unlinked records and externally shared links have only the evidence already captured in the system.

Verification covers a converted lead, linked quotation, email, chat, booking and finance records, an unrelated customer, employee versus admin access, pagination and browser navigation from the directory.
